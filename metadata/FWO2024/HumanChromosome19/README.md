# Human Chromosome 19 Data

## References

We utilized 1000 haplotypes of human chromosome 19 from the 1000 Genomes Project. The data can be accessed [here](http://dolomit.cs.tu-dortmund.de/tudocomp/chr19.1000.fa.xz). This file was originally created for [PHONI: Streamed Matching Statistics with Multi-Genome References](https://doi.org/10.1109/DCC50243.2021.00027).

To create a pan-genome with X number of human chromosome 19 haplotypes, we simply select the first X haplotypes from this file.

## Reads

We randomly sampled 100,000 single-end 151bp reads from the read set with accession SRR17981962, which is accessible [here](https://www.ebi.ac.uk/ena/browser/view/SRR17981962).
