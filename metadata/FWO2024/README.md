# Data for FWO Proposal 2024

This repository contains the data utilized for the experiments in the FWO proposal 2024.

The data is organized in four subdirectories, one for each set of experiments:

- [HumanPangenome](HumanPangenome/): Data for the experiments with human pan-genomes.

- [BacterialPangenome](BacterialPangenome/): Data for the experiments with large bacterial pan-genomes.

- [HumanChromosome19](HumanChromosome19/): Data for the experiments with human chromosome 19 haplotypes.

- [EColi](EColi/): Data for the experiments with E. coli strains.
