# Human pan-genome data

## References

We utilized all 94 human genome haplotypes from the [Human Pangenome Reference Consortium](https://humanpangenome.org/). The data can be accessed [here](https://humanpangenome.org/data/).

The resulting files were shuffled, generating the list available [here](metadata.tsv).

To create a pan-genome with X human genome haplotypes, we simply select the first X haplotypes from this list.
